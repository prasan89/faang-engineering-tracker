# FAANG Engineering Tracker

A personal 26-week preparation dashboard for Google / Amazon / Meta-level software engineering roles.

## Focus
- DSA and coding interviews
- Deep Java and modern Java
- JVM internals, GC, JFR and performance engineering
- Concurrency
- Distributed systems
- System design
- AI / LLM / RAG / agents
- Projects and engineering evidence
- Technical writing, open source, networking and referrals
- Interview and application pipeline

## Stack
Next.js + TypeScript starter, designed to evolve into PostgreSQL + Prisma + authentication + Vercel.

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Roadmap
The initial roadmap is stored in `data/roadmap.json` and covers all 26 weeks.
